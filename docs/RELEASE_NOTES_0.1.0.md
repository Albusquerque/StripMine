# StripMine v0.1.0

StripMine turns one persistent mining shift into three connected views: a full television game, a Decky control room, and a live story on the Steam Machine's 17-LED light bar.

This first release includes:

- a five-age, 30-vein campaign with four miners and permanent twin-city growth;
- four tempo modes from contemplative to frantic;
- Signal Strike, Hold / Bank Convoy, and Overcharge player actions;
- a rotating five-card Decky Dot Matrix with audio, display, pause, and reset controls;
- Luminous and Contrasted profiles shared across the game, Decky, and physical LEDs;
- synchronized pickaxe impacts, mineral-coloured cargo, scoring, promotions, rewards, and adaptive procedural music;
- music and SFX enabled by default, with remembered ON/OFF choices and independent volume controls;
- a first-launch cinematic, workshop upgrades, persistent saves, and a four-act Metropolis finale.

## Install with Decky Loader

StripMine is a sideloaded Decky Loader plugin and is not yet listed in the Decky Plugin Store. Install Decky Loader first, then in Gaming Mode open **Quick Access (`…`) → Decky → Settings (gear) → General**, enable **Developer mode**, and open **Developer**.

Choose **Install Plugin from URL** and paste:

`https://github.com/Albusquerque/StripMine/releases/download/v0.1.0/StripMine-v0.1.0.zip`

Alternatively, download the `StripMine-v0.1.0.zip` release asset and select it with **Install Plugin from ZIP File**. Do not extract the archive and do not use GitHub's automatically generated “Source code” ZIP. If StripMine does not immediately appear, reload or restart Decky Loader, or reboot the device. Then open **Quick Access (`…`) → Decky → StripMine → Enter the mine**.

The physical LED path is implemented, but final brightness and diffusion tuning must be validated on the target Steam Machine.

See the [interactive concept](https://albusquerque.github.io/stripmine-concept-site/) for all three surfaces.
